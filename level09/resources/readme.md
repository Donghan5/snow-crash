# Find the Flag09 Password

When we log in as `level09`, we can see the `level09` executable and a `token` file in the home directory, similar to `level08`.

Run the executable with the `token` file:

```sh
./level09 token
tpmhr
```

The output does not look like the real token. Try inspecting the program with `ltrace`:

```sh
level09@SnowCrash:~$ ltrace ./level09 token
__libc_start_main(0x80487ce, 2, 0xbffff7d4, 0x8048aa0, 0x8048b10 <unfinished ...>
```

The `ptrace()` call is an anti-debugging check. When the program is already being traced by `ltrace`, `ptrace()` fails and returns `-1`, so the program prints:

```text
You should not reverse this
```

The `token` file also contains non-ASCII bytes, so `cat` cannot show it clearly. Use `xxd` to inspect the raw bytes:

```sh
xxd token
0000000: 6634 6b6d 6d36 707c 3d82 7f70 826e 8382  f4kmm6p|=..p.n..
0000010: 4442 8344 757b 7f8c 890a                 DB.Du{....
```

Now test how `level09` transforms input:

```sh
level09@SnowCrash:~$ ./level09 token
tpmhr
level09@SnowCrash:~$ ./level09 aaaaaaa
abcdefg
level09@SnowCrash:~$ ./level09 abcdefg
acegikm
level09@SnowCrash:~$ ./level09 00000
01234
```

From these tests, each output character is generated by adding the character index to the original ASCII value:

```text
output[i] = input[i] + i
```

For example, `aaaaaaa` becomes `abcdefg` because each `a` is shifted by its index: `a + 0`, `a + 1`, `a + 2`, and so on.

To recover the original password from the encoded `token` file, reverse the rule:

```text
input[i] = output[i] - i
```

## Decode the Token

Write a small script that subtracts the byte index from each byte in the `token` file:

```sh
vi /tmp/reverse.py
```

```python
#!/usr/bin/python
from pathlib import Path

TOKEN_PATH = Path("/home/user/level09/token")

try:
    content = TOKEN_PATH.read_bytes()
except OSError as e:
    raise SystemExit(f"failed to read token: {e}")

content = content.rstrip(b"\n")

for i, byte in enumerate(content):
    decoded = byte - i

    if not 0 <= decoded <= 127:
        raise ValueError(
            f"decoded value out of ASCII range: "
            f"index={i}, encoded={byte}, decoded={decoded}"
        )

    print(chr(decoded), end="")
```

Run the script:

```sh
level09@SnowCrash:~$ python /tmp/reverse.py
f3iji1ju5yuevaus41q1afiuq
```

The decoded value is the password for `flag09`. Log in as `flag09`, then run `getflag` to get the token for the next level.
